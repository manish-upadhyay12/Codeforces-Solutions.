## Problem Statement

<div class="header"><div class="title">B. Serval и Инверсионная магия</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>У Serval есть бинарная строка $$$s$$$, которая может состоять только из символов <span class="tex-font-style-tt">0</span> и <span class="tex-font-style-tt">1</span>, длины $$$n$$$. $$$i$$$-й символ $$$s$$$ обозначается как $$$s_i$$$, где $$$1\leq i\leq n$$$.</p><p>Serval может применять следующую операцию, названную Инверсионной магией, к строке $$$s$$$: </p><ul> <li> Выбрать отрезок $$$[l, r]$$$ ($$$1\leq l\leq r\leq n$$$). Для $$$l\leq i\leq r$$$, заменить $$$s_i$$$ на <span class="tex-font-style-tt">1</span>, если $$$s_i$$$ является <span class="tex-font-style-tt">0</span>, и заменить $$$s_i$$$ на <span class="tex-font-style-tt">0</span>, если $$$s_i$$$ является <span class="tex-font-style-tt">1</span>. </li></ul><p>Например, пусть $$$s$$$ равна <span class="tex-font-style-tt">010100</span> и выбран отрезок $$$[2,5]$$$. Строка $$$s$$$ будет равна <span class="tex-font-style-tt">001010</span> после применения Инверсионной магии.</p><p>Serval хочет сделать $$$s$$$ палиндромом после применения Инверсионной магии <span class="tex-font-style-bf">ровно один раз</span>. Помогите ему определить, возможно ли это.</p><p>Строка является палиндромом тогда и только тогда, когда она одинаково читается слева направо и справа налево. Например, <span class="tex-font-style-tt">010010</span> является палиндромом, но <span class="tex-font-style-tt">10111</span> не является.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. Первая строка содержит количество наборов входных данных $$$t$$$ ($$$1\leq t\leq 10^4$$$). Далее следует описание наборов входных данных.</p><p>Первая строка каждого набора входных данных содержит единственное целое число $$$n$$$ ($$$2\leq n\leq 10^5$$$) — длина строки $$$s$$$.</p><p>Вторая строка каждого набора входных данных содержит бинарную строку $$$s$$$ длины $$$n$$$. В строке $$$s$$$ могут содержаться только символы <span class="tex-font-style-tt">0</span> и <span class="tex-font-style-tt">1</span>.</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превосходит $$$2\cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входых данных выведите <span class="tex-font-style-tt">Yes</span>, если $$$s$$$ может стать палиндромом, после применения Инверсионной магии один раз, и <span class="tex-font-style-tt">No</span>, если нет.</p><p>Вы можете вывести <span class="tex-font-style-tt">Yes</span> и <span class="tex-font-style-tt">No</span> в любом регистре (например, строки <span class="tex-font-style-tt">yEs</span>, <span class="tex-font-style-tt">yes</span>, <span class="tex-font-style-tt">Yes</span> и <span class="tex-font-style-tt">YES</span> будут распознаны как положительный ответ).</p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id008021812104361163" id="id0046891352034574707" class="input-output-copier">Скопировать</div></div><pre data-content="3
